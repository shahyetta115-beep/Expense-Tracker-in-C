# Expense-Tracker-in-C
A beginner-friendly C console application that allows users to add, view, categorize, and calculate their personal expenses.
## About the Project
Personal Expense Tracker is a simple C console-based application that helps users record and manage their daily expenses. It allows users to add, view, search, and analyze their expenses through a menu-driven interface.
## Features
- Add new expenses
- View all expenses
- Calculate total spending
- Find the highest expense
- Search expenses by category
- Simple menu-driven interface
## Technologies Used
- C Language
- Structures
- Arrays
- Functions
- Loops
- Conditional Statements
- String Handling
## How It Works
The program provides a menu where the user can choose different options to manage their expenses.
Example:
1. Add Expense
2. View Expenses
3. Calculate Total Spending
4. Show Highest Expense
5. Search by Category
6. Exit
